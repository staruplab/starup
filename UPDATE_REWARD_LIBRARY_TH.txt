STAR UP! ROUND 4 — คลังของรางวัล

สิ่งที่เพิ่ม:
- คลังของรางวัลส่วนตัวของบัญชีครู บันทึกใน Supabase
- สร้าง/แก้ไข/ลบรายการในคลังได้
- บันทึกของรางวัลจากห้องปัจจุบันเข้าคลังได้
- เลือกของรางวัลหลายรายการจากคลัง แล้วเพิ่มเข้าห้องที่กำลังเลือกได้พร้อมกัน
- ของรางวัลที่เพิ่มเข้าห้องจะเป็นรายการแยกใน reward_items ของห้องนั้น
- เปลี่ยนห้องแล้วรายการของรางวัลที่แสดงยังคงแยกตามห้องเหมือนเดิม
- ป้องกันการเพิ่มชื่อซ้ำในห้องเดียวกัน

ติดตั้ง:
1. สำรองโปรเจกต์เดิม
2. Supabase > SQL Editor > New query
3. เปิด migration_reward_library.sql คัดลอกทั้งหมดแล้ว Run
4. อัปโหลดไฟล์ทั้งหมดใน STAR_UP_MISSIONS ไปยัง GitHub โดยคงโฟลเดอร์ teacher/ และ student/ ไว้
5. เปิด /teacher/ แล้วกด Ctrl+Shift+R

ตัวอย่าง:
เพิ่ม iPhone 18 Pro Max ราคา 1,000 ดาวเข้าคลัง
เลือกห้อง ป.5/7 แล้วติ๊กเลือก iPhone เพื่อเพิ่มเข้าห้อง
เปลี่ยนไปห้องอื่น เลือกคลัง แล้วติ๊กเพิ่ม iPhone ให้ห้องนั้นได้อีกครั้ง

หมายเหตุ:
- คลังเป็นของบัญชีครูแต่ละบัญชี ไม่ใช่คลังส่วนกลางของครูทุกคน
- รายการในคลังเป็นแม่แบบ เมื่อติดตั้งเข้าห้องจะคัดลอกข้อมูลไปเป็น reward_items ของห้องนั้น
- การลบแม่แบบจากคลังไม่ลบของรางวัลที่เพิ่มไว้ในห้องแล้ว
- สิทธิ์ RLS จำกัดให้ครูเห็นและแก้ไขเฉพาะคลังของบัญชีตนเอง
