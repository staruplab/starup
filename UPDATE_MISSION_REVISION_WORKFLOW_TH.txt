STAR UP! — อัปเดตระบบส่งกลับแก้ไขภารกิจ

สิ่งที่ปรับ:
1. หน้าตรวจหลักฐานของครูแสดงคอมเมนต์นักเรียน วันและเวลาที่ส่ง พร้อมภาพ
2. เพิ่มปุ่ม "ส่งกลับแก้ไข" แยกจาก "ไม่อนุมัติ" และ "อนุมัติ"
3. การส่งกลับแก้ไขต้องระบุเหตุผล และบันทึกเป็นสถานะ needs_revision
4. แอปนักเรียนแสดงหน้าต่างแจ้งเตือน พร้อมชื่อภารกิจ เหตุผล และเวลาส่ง/เวลาส่งกลับ
5. หน้าต่างจะปรากฏอีกเมื่อกลับเข้าระบบจนกว่านักเรียนกดรับทราบ (จำสถานะรับทราบในอุปกรณ์นั้น)
6. นักเรียนส่งหลักฐานใหม่ได้หลังถูกส่งกลับแก้ไข ประวัติการส่งเดิมยังคงอยู่
7. การไม่อนุมัติยังคงใช้สถานะ rejected และไม่ให้ดาว; อนุมัติยังใช้ RPC เดิมและให้ดาวตามระบบเดิม
8. เปลี่ยนชื่อ cache ของ PWA เพื่อให้เบราว์เซอร์โหลดไฟล์เวอร์ชันใหม่

ก่อนใช้งาน:
- สำรองฐานข้อมูลก่อน
- เปิด Supabase Dashboard > SQL Editor
- รันไฟล์ migration_mission_revision_workflow.sql หนึ่งครั้ง
- อัปโหลดไฟล์ทั้งหมดใน ZIP ไปยัง Repository เดิม โดยคงโครงสร้างโฟลเดอร์
- ทดสอบด้วยบัญชีนักเรียนและครูจริง

ข้อควรทราบ:
- ยังไม่ได้เชื่อมต่อ Supabase จริงในสภาพแวดล้อมนี้ จึงยังไม่ได้ทดสอบ RPC/สิทธิ์/Storage แบบ end-to-end
- การรับทราบหน้าต่างแจ้งเตือนถูกจำใน localStorage ของอุปกรณ์/เบราว์เซอร์นั้น หากเปิดจากอุปกรณ์อื่นอาจแสดงอีกครั้ง
- ไม่ต้องรัน migration เดิมซ้ำ ให้รันเฉพาะ migration ใหม่ไฟล์นี้
