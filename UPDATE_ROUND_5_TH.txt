STAR UP! UPDATE ROUND 5 — REVISION 1

สิ่งที่ปรับปรุง
- ปรับโลโก้ในหน้าแอปให้ใช้แอนิเมชันโลโก้กลมเป็นจุดเด่น และปรับ splash รองรับ safe area / dynamic viewport ของ iOS
- เปลี่ยนช่องหมวดหมู่ภารกิจเป็น select เพื่อให้เลือกหมวดหมู่ที่บันทึกไว้ได้สะดวกบนมือถือ
- ภารกิจด่วนกำหนดวันเวลาเริ่มต้นและสิ้นสุด พร้อมแสดงเวลาคงเหลือ
- นักเรียนเห็นป๊อปอัปภารกิจด่วนหลายรายการ เลื่อนดูได้ และต้องกดปุ่มปิดเองเท่านั้น ไม่มีเวลานับถอยหลังเพื่อปิดหน้าต่างอัตโนมัติ ภารกิจยังคงอยู่ในหน้าภารกิจ
- เพิ่มปุ่มลบของรางวัลทีละรายการและลบทั้งหมดเฉพาะของรางวัลในห้องที่เลือก (ไม่ลบคลังส่วนตัว)

ติดตั้ง
1) สำรองไฟล์ใน GitHub repository ก่อน
2) รัน migration_urgent_missions_categories_leave.sql ใน Supabase SQL Editor หนึ่งครั้ง เพื่อเพิ่ม start_at และอัปเดต get_student_portal
3) อัปโหลดเนื้อหาทั้งหมดในโฟลเดอร์ STAR_UP_MISSIONS ไปทับไฟล์เดิมใน repository starup โดยคงโครงสร้างโฟลเดอร์
4) Commit changes แล้วรอ GitHub Pages deploy
5) รีเฟรชแบบไม่ใช้แคช: Mac Command+Shift+R; iPhone/Android ปิดแอปแล้วเปิดใหม่ หรือ clear site data หากยังเห็นเวอร์ชันเก่า

หมายเหตุ
- ไอคอนติดตั้ง PWA ยังเป็นไฟล์สี่เหลี่ยมตามข้อกำหนด Android/iOS แต่ภาพโลโก้ภายในถูกครอบเป็นวงกลม
- การแจ้งเตือนทำงานเมื่อเปิดแอปอยู่และมีการตรวจสอบข้อมูลเป็นระยะ ไม่ใช่ push notification เมื่อปิดแอป
- ควรทดสอบบนบัญชี/ห้องทดสอบก่อนใช้งานจริง
