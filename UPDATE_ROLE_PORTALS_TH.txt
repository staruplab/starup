STAR UP! — อัปเดตแยกแอปครู/นักเรียน และปรับแท็บสถานะนักเรียน

สิ่งที่แก้ไข
1) ลิงก์ ?portal=teacher เลือก manifest ของแอปครู ซึ่งเปิดแอปที่ ?portal=teacher โดยตรง
2) ลิงก์ ?portal=student เลือก manifest ของแอปนักเรียน ซึ่งเปิดแอปที่ ?portal=student โดยตรง
3) เปลี่ยน Service Worker cache เป็น v6 และเพิ่ม manifest แยกบทบาททั้งสองไฟล์
4) เปลี่ยนชื่อแท็บเป็น “📊 ดูหน้าจอสถานะนักเรียน” และปรับไอคอนหัวข้อเป็นกราฟสถานะในกรอบไล่สีม่วง-เหลือง
5) ไม่แก้ฐานข้อมูล, SQL, QR token, โลโก้ หรือข้อมูลนักเรียนเดิม

ไฟล์ที่ต้องอัปโหลดทับ/เพิ่มใน Repository (ที่ root /starup)
- index.html (อัปโหลดทับ)
- sw.js (อัปโหลดทับ)
- manifest-teacher.webmanifest (เพิ่มไฟล์ใหม่)
- manifest-student.webmanifest (เพิ่มไฟล์ใหม่)

ไฟล์ manifest.webmanifest เดิมยังคงไว้สำหรับหน้าแรกเลือกบทบาท

ลิงก์ทดสอบ
- ครู: https://staruplab.github.io/starup/?portal=teacher
- นักเรียน: https://staruplab.github.io/starup/?portal=student
- หน้าเลือกบทบาทเดิม: https://staruplab.github.io/starup/

ขั้นตอนติดตั้ง
1) อัปโหลดไฟล์ตามรายการไปยัง root ของ repository (อย่าวางไว้ในโฟลเดอร์ย่อย)
2) Commit และรอ GitHub Pages deploy สำเร็จ
3) เปิดลิงก์ครูจาก Chrome แล้วเลือกติดตั้งแอป เพื่อสร้างแอปครู
4) เปิดลิงก์นักเรียนจาก Chrome แล้วเลือกติดตั้งแอป เพื่อสร้างแอปนักเรียน
5) หากเคยติดตั้ง STAR UP! เวอร์ชันเดิมไว้ ให้ถอนการติดตั้งเวอร์ชันเดิมก่อน แล้วติดตั้งแยกใหม่จากแต่ละลิงก์ เพื่อให้เบราว์เซอร์อ่าน manifest และ app id ใหม่
6) ทดสอบเปิดไอคอนแอปครูและนักเรียนแยกกัน ต้องเข้าหน้าล็อกอินของบทบาทนั้นโดยตรง ไม่กลับไปหน้าเลือกบทบาท

หมายเหตุ
- เมื่อมี session ครูอยู่ แอปครูจะเข้าสู่ระบบครูตามปกติ ส่วนแอปนักเรียนจะออกจาก session ครูในเบราว์เซอร์เดียวกันก่อนแสดงหน้าเข้าสู่ระบบนักเรียน เพื่อไม่ให้เห็นหน้าผิดบทบาท
- การแยกหน้าจอเป็นการแยกประสบการณ์ใช้งาน ไม่ทดแทนการกำหนดสิทธิ์ Supabase RLS/RPC
- ตรวจสอบ syntax JavaScript ด้วย Node.js แล้ว ผ่านทุก script block
