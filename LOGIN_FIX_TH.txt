STAR UP! — แก้ไขปุ่มเข้าสู่ระบบครู

สาเหตุ:
หน้าเข้าสู่ระบบเรียก onclick="signIn()" แต่ใน index.html ไม่มีการประกาศฟังก์ชัน signIn()
จึงกดปุ่มแล้วไม่สามารถเรียกการเข้าสู่ระบบ Supabase ได้

การแก้ไข:
- เพิ่ม signIn() โดยใช้ Supabase Auth signInWithPassword
- ตรวจสอบอีเมลและรหัสผ่านก่อนส่ง
- ป้องกันการกดซ้ำระหว่างกำลังเข้าสู่ระบบ
- แสดงข้อความกรณีรหัสผ่านผิด / ยังไม่ยืนยันอีเมล / ข้อผิดพลาดจากระบบ
- โหลดข้อมูลครูและห้องเรียนหลังเข้าสู่ระบบสำเร็จ
- รองรับลิงก์คำเชิญเข้าห้องเรียน

การอัปเดต:
1. แตก ZIP นี้
2. อัปโหลด index.html ไปแทนที่ index.html เดิมใน GitHub Repository (ระดับเดียวกัน)
3. อัปโหลด LOGIN_FIX_TH.txt เพิ่มไว้เป็นบันทึกก็ได้
4. Commit changes
5. รอ GitHub Pages เผยแพร่ แล้วเปิดเว็บใหม่/ล้างแคชเว็บไซต์
6. ทดสอบเข้าสู่ระบบครู

ไม่ต้องรัน SQL หรือ Migration เพิ่มเพื่อแก้ปุ่มเข้าสู่ระบบนี้
