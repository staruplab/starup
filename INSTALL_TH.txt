STAR UP! — วิธีอัปเดตและติดตั้ง PWA (GitHub Pages)

ไฟล์ในชุดนี้
- index.html: เว็บแอป (รวมระบบยืนยันลบห้องแบบปุ่ม ยกเลิก/ยืนยัน)
- manifest.webmanifest: ข้อมูลแอปสำหรับเบราว์เซอร์ ใช้ URL /starup/
- manifest.json: สำเนาสำรองเพื่อรองรับการอ้างอิงเดิม
- sw.js: Service Worker สำหรับ PWA และแคชเวอร์ชันใหม่
- icon-192.png, icon-512.png: ไอคอน PWA
- apple-touch-icon.png, favicon-32.png, favicon.ico: ไอคอนเบราว์เซอร์/มือถือ
- logo-star-up.jpg: โลโก้ภายในเว็บ
- migration_missions.sql: SQL เดิมของระบบภารกิจ (ไม่ได้แก้ไขในงาน PWA นี้)

วิธีอัปเดต GitHub
1. สำรอง Repository หรือดาวน์โหลด ZIP ปัจจุบันเก็บไว้ก่อน
2. แตก ZIP นี้ แล้วเปิดโฟลเดอร์ STAR_UP_MISSIONS
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยังระดับเดียวกับ index.html ใน branch main ของ Repository ที่เผยแพร่ที่ https://staruplab.github.io/starup/
4. เลือกแทนที่ไฟล์ชื่อซ้ำ ได้แก่ index.html, sw.js, manifest.webmanifest, manifest.json, ไฟล์ไอคอน และ logo-star-up.jpg
5. เก็บ README_TH.txt, migration_v4.sql และ schema.sql เดิมใน GitHub ไว้ ไม่ต้องลบ
6. ห้ามรัน migration_missions.sql, migration_v4.sql หรือ schema.sql ซ้ำเพียงเพื่อแก้ PWA
7. Commit changes แล้วรอ GitHub Pages เผยแพร่

วิธีตรวจสอบไฟล์หลังอัปเดต
เปิด URL ต่อไปนี้ในเบราว์เซอร์ ต้องไม่เป็น 404:
- https://staruplab.github.io/starup/manifest.webmanifest
- https://staruplab.github.io/starup/sw.js
- https://staruplab.github.io/starup/icon-192.png
- https://staruplab.github.io/starup/icon-512.png

วิธีติดตั้งบน Android/Brave
1. เปิด https://staruplab.github.io/starup/ ผ่าน HTTPS
2. รีเฟรชหน้าเว็บ แล้วรอให้ Service Worker ลงทะเบียน
3. เปิดเมนู Brave (⋮) แล้วตรวจว่ามี “ติดตั้งแอป” หรือ “เพิ่มลงในหน้าจอหลัก”
4. หากยังไม่ขึ้น ให้ปิดแท็บ เปิดเว็บใหม่ และรอสักครู่ จากนั้นตรวจ URL ด้านบนอีกครั้ง
5. หากเคยติดตั้ง/เคยเปิดเว็บมาก่อน ให้ล้างข้อมูลเว็บไซต์ของ staruplab.github.io แล้วเปิดใหม่เพื่อให้รับ manifest และ Service Worker รุ่นใหม่

หมายเหตุสำคัญ
- PWA ต้องเปิดผ่าน HTTPS และต้องเข้าผ่าน path /starup/ ตามที่กำหนดใน manifest
- การมีปุ่มติดตั้งในหน้าเว็บไม่ได้บังคับให้ Brave แสดงหน้าติดตั้งเสมอไป; เบราว์เซอร์เป็นผู้ตัดสินจากเงื่อนไขและสถานะของเว็บไซต์
- ไฟล์ชุดนี้ไม่ได้เชื่อมต่อ GitHub ให้โดยตรง และยังต้องอัปโหลด/ทดสอบบนอุปกรณ์จริง
- ไม่ได้เปลี่ยนค่า Supabase, schema.sql หรือ migration เดิม
