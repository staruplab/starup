STAR UP! ระบบภารกิจความดี — รุ่นปรับปรุง

ไฟล์ในชุดนี้:
- index.html: เว็บแอปที่เพิ่มหมวดหมู่ภารกิจ วันหมดเขต และสถานะสำเร็จแล้ว
- migration_missions.sql: ตารางภารกิจ/หลักฐาน, Storage bucket, RPC ตรวจและอนุมัติ พร้อมกติกาไม่ให้รับรางวัลภารกิจเดิมซ้ำ

ติดตั้ง:
1) สำรอง index.html และฐานข้อมูลเดิมก่อน
2) Supabase Dashboard > SQL Editor > New query > วาง migration_missions.sql ทั้งไฟล์ > Run
3) ตรวจว่าไม่มี error และ Storage มี bucket mission-evidence (private)
4) อัปโหลด index.html นี้แทนไฟล์เดิมใน GitHub repository
5) Commit changes แล้วรอ GitHub Pages เผยแพร่
6) ทดสอบด้วยบัญชีครูและ QR นักเรียนจริง ทั้งการส่งรูป อนุมัติ ปฏิเสธ และส่งใหม่

คุณสมบัติเพิ่ม:
- ครูเลือกหมวดหมู่ภารกิจและกำหนดวันหมดเขตได้
- นักเรียนเห็นหมวดหมู่/วันหมดเขตและสถานะสำเร็จ
- นักเรียนรับดาวจากภารกิจเดิมได้ครั้งเดียว; หากถูกปฏิเสธยังแก้ไขและส่งใหม่ได้
- การอนุมัติใช้ RPC ฝั่งฐานข้อมูลและล็อกแถวเพื่อป้องกันการอนุมัติซ้ำ

ข้อควรทราบ:
- SQL นี้ออกแบบให้รันต่อจาก migration_missions.sql รุ่นก่อนในชุดเดิม ไม่ใช่แทน schema.sql
- ถ้ามีรายการอนุมัติซ้ำเก่าก่อนติดตั้ง ระบบจะเก็บรายการแรกและเปลี่ยนรายการซ้ำเป็น rejected โดยไม่ปรับยอดดาวย้อนหลัง
- โหมดทดลองในเบราว์เซอร์ไม่รองรับการส่งรูปจริง ต้องใช้ Supabase ออนไลน์
- ห้ามใส่ service_role key ใน index.html
- ภาพหลักฐานเป็นข้อมูลส่วนตัวของนักเรียน ควรให้ครูที่ได้รับอนุญาตเท่านั้นเข้าดู และลบภาพตามนโยบายโรงเรียนเมื่อหมดความจำเป็น
