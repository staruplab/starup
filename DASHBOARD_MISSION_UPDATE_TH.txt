STAR UP! — อัปเดต Dashboard ภารกิจ

สิ่งที่ปรับในเวอร์ชันนี้
1. Dashboard ครูแสดงเฉพาะภารกิจที่ยังเปิดใช้งานและยังไม่ถึงกำหนดสิ้นสุด
2. ภารกิจที่หมดเวลาหรือครูปิด จะถูกซ่อนจากรายการหลัก แต่ยังเก็บข้อมูลและหลักฐานเดิมไว้
3. เพิ่มปุ่ม “ดูประวัติภารกิจ” เพื่อเปิดดูภารกิจที่หมดเวลาหรือถูกปิด
4. แสดงจำนวนผู้สำเร็จแยกเป็นรายนักเรียน โดยไม่ปิดหรือซ่อนภารกิจเพียงเพราะมีนักเรียนบางคน/ทุกคนได้รับอนุมัติ
5. เพิ่มเวลาคงเหลือของแต่ละภารกิจ และอัปเดตนับถอยหลังทุกวินาที
6. เมื่อหมดเวลา ระบบจะนำภารกิจออกจากรายการที่กำลังดำเนินอยู่โดยอัตโนมัติ

หมายเหตุ
- แก้ไขเฉพาะ teacher/index.html และเพิ่มเอกสารนี้
- ไม่แก้ไข schema.sql หรือ migration ใด ๆ และไม่ต้องรัน SQL เพิ่ม
- การปิด/เปิดภารกิจยังใช้ฟิลด์ active เดิม
- วันหมดเขตใช้ due_at เดิม และภารกิจด่วนใช้ urgent_until เดิม
- กรุณาทดสอบบนสำเนา/Preview ก่อนเผยแพร่ GitHub Pages
