STAR UP! — แยกลิงก์ครูและนักเรียน (คงโลโก้เดิม)

ลิงก์หน้าเลือกประเภท: https://staruplab.github.io/starup/
ลิงก์ครู: https://staruplab.github.io/starup/?portal=teacher
ลิงก์นักเรียน: https://staruplab.github.io/starup/?portal=student

วิธีอัปเดต:
1) แตก ZIP นี้
2) อัปโหลด index.html ทับไฟล์เดิมที่ root ของ Repository (โฟลเดอร์ starup)
3) อัปโหลด sw.js ทับไฟล์เดิม เพื่อเปลี่ยน cache version และให้ผู้ใช้โหลดหน้าใหม่
4) Commit changes และรอ GitHub Pages deploy
5) ทดสอบลิงก์นักเรียน: ต้องเห็นเฉพาะหน้าสแกน QR/กรอกรหัส ไม่มีแท็บครูและไม่มีสมัครครู
6) ทดสอบลิงก์ครู: ต้องเห็นเฉพาะหน้าเข้าสู่ระบบครู
7) ทดสอบ QR นักเรียนเดิม: QR เดิมที่มี ?student=... ต้องยังเปิดหน้าโปรไฟล์เดิมได้

ข้อควรทราบด้านความปลอดภัย:
การแยกลิงก์เป็นการแยกประสบการณ์และลดการเข้าผิดหน้า ไม่ใช่การควบคุมสิทธิ์แทน Supabase RLS. การป้องกันข้อมูลจริงยังต้องบังคับสิทธิ์ที่ฐานข้อมูล/RPC และห้ามเปิดสิทธิ์ครูด้วยการซ่อนปุ่มเพียงอย่างเดียว. ไม่ได้เปลี่ยน schema หรือข้อมูลเดิม และไม่แก้ไขไฟล์โลโก้เดิม.
