STAR UP! — อัปเดตหน้าจอและระบบแนบภาพภารกิจ

ไฟล์ที่เปลี่ยน:
- index.html: ปรับเลย์เอาต์มือถือให้สมมาตร, ปรับระบบแนบ/แก้ไข/ลบภาพได้สูงสุด 4 ภาพ,
  รวมการถ่ายภาพจากกล้องและเลือกจากเครื่อง, แสดงหน้าต่างกำลังเตรียม/กำลังส่ง/ส่งสำเร็จ,
  แก้ฟังก์ชันส่งภารกิจซ้ำซ้อนที่ทำให้โค้ดส่งภาพหลายภาพถูกฟังก์ชันเก่าทับ,
  แสดงรหัสอ้างอิงนักเรียนแบบ 4 ตัวอักษร S001, S002, ...
- sw.js: เพิ่ม cache version เป็น v5 เพื่อให้มือถือโหลดไฟล์ใหม่

สำคัญ:
- รหัส S001 ฯลฯ เป็นรหัสอ้างอิงแสดงในหน้าจอครูเท่านั้น ไม่ใช่รหัสผ่าน/รหัสแทน QR
  QR เดิมยังคงใช้ token ที่ยาวและปลอดภัยกว่า ห้ามลดความยาว token ในฐานข้อมูล
- ไม่แก้บัญชีครู, student QR token, ข้อมูลห้องเรียน, นักเรียน, ดาว หรือฐานข้อมูล
- ระบบแนบภาพหลายภาพใช้ migration_missions_multi_image_unlimited_stars.sql ที่มีอยู่แล้ว
  หากยังไม่เคยรัน migration นี้ใน Supabase ให้รันตามคู่มือเดิมก่อนใช้งานหลายภาพ
- ไม่ต้องรัน SQL ใหม่สำหรับการแก้ไขรอบนี้

วิธีอัปเดต GitHub Pages:
1. แตก ZIP
2. เปิดโฟลเดอร์ STAR_UP_MISSIONS
3. อัปโหลด index.html และ sw.js ทับไฟล์เดิมใน root ของ repository
4. Commit changes และรอ GitHub Pages deploy
5. ปิดแท็บ/หน้าต่าง STAR UP! ที่เปิดอยู่ทั้งหมด แล้วเปิดเว็บไซต์ใหม่
6. ทดสอบในโหมดนักเรียน > ภารกิจ > เลือกภาพ/ถ่ายภาพ > ลองแก้ไขหรือลบภาพ > ส่งภาพ

การทดสอบ:
- ตรวจสอบ JavaScript syntax และ ZIP integrity แล้ว
- ยังต้องทดสอบการอัปโหลดจริงกับ Supabase Storage และอุปกรณ์มือถือหลังเผยแพร่
