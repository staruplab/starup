STAR UP! — UPDATE ROUND 3
=========================

สิ่งที่เพิ่มในรอบนี้
1) ภารกิจด่วน
   - ครูติ๊ก "กำหนดเป็นภารกิจด่วน" ขณะสร้างภารกิจได้
   - กำหนดเวลาทำภารกิจ 1–1,440 นาที
   - กำหนดเวลาที่หน้าต่างแจ้งเตือนแสดง 5–30 วินาที
   - แอปนักเรียนที่เปิดค้างอยู่จะตรวจภารกิจใหม่ทุก 5 วินาทีผ่าน RPC get_student_portal
   - เมื่อพบภารกิจด่วนใหม่ จะแสดงหน้าต่างแจ้งเตือน มีเสียงเตือน ปุ่มไปยังภารกิจ และปิดเองตามเวลาที่กำหนด
   - ภารกิจด่วนแสดงป้าย/กรอบพิเศษในหน้า ภารกิจ ของนักเรียน
   - ถ้านักเรียนไม่ได้เปิดแอปตอนครูสร้างภารกิจ จะไม่เห็นหน้าต่างเด้งย้อนหลัง แต่ยังเห็นภารกิจในหน้ารายการได้ตราบใดที่ยังไม่หมดเขต

2) หมวดหมู่ภารกิจ
   - เพิ่ม/แก้ไข/ลบหมวดหมู่ได้จากปุ่ม "จัดการหมวดหมู่"
   - หมวดหมู่เก็บแยกตามห้องเรียนในตาราง mission_categories
   - หากพิมพ์หมวดหมู่ใหม่ตอนสร้างภารกิจ ระบบจะบันทึกหมวดหมู่นั้นให้อัตโนมัติ
   - การลบหมวดหมู่ไม่ลบภารกิจเก่าที่ใช้หมวดหมู่นั้น

3) รูปโปรไฟล์และทีมครู
   - เพิ่มตัวเลือกไอคอน/รูปโปรไฟล์แบบ Emoji ให้เลือกมากขึ้น
   - ปรับการ์ดทีมครูให้มีกรอบและพื้นหลังไล่สี
   - ใช้ profile_icon เดียวกับโปรไฟล์ครูในรายการทีมครู และโหลดข้อมูลทีมใหม่หลังบันทึกโปรไฟล์

4) ออกจากห้องเรียน
   - ครูที่มี role เป็น teacher จะเห็นปุ่ม "ออกจากห้อง" พร้อมหน้าต่างยืนยัน
   - ข้อมูลห้อง นักเรียน ดาว และประวัติไม่ถูกลบเมื่อครูออก
   - เจ้าของห้องยังคงเป็นเจ้าของและไม่สามารถออกจากห้องผ่านปุ่มนี้ได้ ต้องโอนสิทธิ์เจ้าของห้องก่อน
   - เจ้าของห้องสามารถสร้างลิงก์เชิญใหม่ให้ครูที่ออกไปแล้วได้ ครูใช้บัญชีเดิมเข้าสู่ระบบ หรือสมัครบัญชีใหม่ด้วยอีเมลอื่นแล้วเปิดลิงก์เชิญได้

วิธีติดตั้ง
1. สำรองไฟล์/Repository ปัจจุบันก่อน
2. รันไฟล์ migration_urgent_missions_categories_leave.sql ใน Supabase SQL Editor เพียง 1 ครั้ง
3. อัปโหลดไฟล์ทั้งหมดใน STAR_UP_MISSIONS ทับไฟล์เดิมในตำแหน่งเดียวกัน โดยคงโฟลเดอร์ teacher/ และ student/ ไว้
4. Commit changes และรอ GitHub Pages deploy
5. ปิดแอป STAR UP! เดิม แล้วเปิดใหม่ หรือถอนติดตั้ง/ติดตั้ง PWA ใหม่หาก Service Worker ยังแสดงหน้าเก่า
6. ทดสอบภารกิจด่วนโดยเปิดแอปนักเรียนค้างไว้ จากนั้นให้ครูสร้างภารกิจด่วน
7. ทดสอบหมวดหมู่โดยเพิ่ม แก้ไข ลบ แล้วรีเฟรชหน้า
8. ทดสอบออกจากห้องด้วยบัญชีครูผู้ร่วมดูแล (ไม่ใช่เจ้าของห้อง) แล้วให้เจ้าของห้องสร้างลิงก์เชิญใหม่

ข้อจำกัดสำคัญ
- การแจ้งเตือนด่วนในรอบนี้ทำงานเมื่อหน้าแอปนักเรียนเปิดอยู่/ทำงานอยู่ โดยตรวจข้อมูลทุก 5 วินาทีผ่าน RPC ที่ตรวจสอบ QR token ไม่ใช่ Push Notification จากระบบปฏิบัติการเมื่อปิดแอปหรือปิดเบราว์เซอร์
- เสียงแจ้งเตือนขึ้นกับการอนุญาตเสียง/นโยบาย autoplay ของเบราว์เซอร์ อุปกรณ์บางรุ่นอาจต้องมีการแตะหน้าจอก่อน
- ยังต้องทดสอบกับ Supabase project จริงหลังรัน migration และ deploy
- เจ้าของห้องออกเองไม่ได้ เพื่อป้องกันห้องไม่มีผู้ดูแล
