ไฟล์อัปเดต STAR UP!

1) สำรอง index.html เดิมก่อน
2) อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า GitHub Repository starup ที่ระดับเดียวกับไฟล์เดิม
3) อนุญาตให้แทนที่ index.html เดิมด้วย index.html ใหม่นี้
4) Commit changes แล้วรอ GitHub Pages เผยแพร่

ไฟล์นี้เปลี่ยนโลโก้หัวแอปทุกตำแหน่งที่เดิมใช้ดาว emoji และตั้งค่า favicon / app icons / manifest แล้ว
อย่าลบไฟล์ schema.sql หรือ migration เดิม
