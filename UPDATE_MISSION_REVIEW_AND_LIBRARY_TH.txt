STAR UP! — ปรับปรุงการตรวจภารกิจและคลังภารกิจ

1) ครูเปิดดูหลักฐานแล้วเห็นข้อความที่นักเรียนเขียนแนบมากับการส่งงานได้
2) ปุ่มตรวจงานแสดงเป็น “ส่งกลับแก้ไข” เมื่อไม่อนุมัติ โดยใส่เหตุผลถึงนักเรียนได้
3) นักเรียนส่งใหม่ได้หลังสถานะถูกส่งกลับแก้ไข ระบบเก็บแต่ละครั้งเป็นรายการแยก และให้ดาวเฉพาะเมื่ออนุมัติ
4) เพิ่มคลังภารกิจส่วนตัวของครู: กด “เก็บเข้าคลัง” จากภารกิจ แล้วเปิด “คลังภารกิจ” เพื่อนำไปคัดลอกใช้ในห้องปัจจุบัน
5) คลังส่วนตัวแยกตามบัญชีครูด้วย Row Level Security

สำคัญ: ก่อนใช้คลังภารกิจ ให้รัน migration_mission_library.sql ใน Supabase Dashboard > SQL Editor
ไฟล์ migration นี้เพิ่มเฉพาะตารางคลังภารกิจ ไม่แก้ตารางภารกิจ/ดาวเดิม
