STAR UP! — อัปเดตหน้าตาแอปครู/นักเรียน

สิ่งที่ปรับ:
1) Splash Screen: โลโก้เดิมแสดงแบบ contain ในกรอบวงกลม ลดขอบเหลี่ยมและไม่ครอปโลโก้
2) โลโก้ในหน้าเข้าสู่ระบบ: ปรับเป็นวงกลมและแสดงภาพเต็ม
3) แอปนักเรียน: เอาปุ่ม “กลับหน้าแรก” ออกจากหน้าล็อกอินนักเรียน และปรับโทนสีเป็นเหลือง/ทอง
4) หน้าแอปครู > ดูหน้าจอสถานะนักเรียน: เปลี่ยนปุ่ม “ดูหน้านักเรียน” เป็น “ดูสถานะ” และปรับหัวคอลัมน์เป็น “สถานะนักเรียน”
5) เพิ่มเวอร์ชันแคช Service Worker เพื่อให้รับไฟล์ใหม่

ไฟล์ที่อัปเดต:
- index.html
- teacher/index.html
- student/index.html
- sw.js
- teacher/sw.js
- student/sw.js

วิธีอัปเดต:
1) สำรอง Repository ก่อน
2) แตก ZIP แล้วอัปโหลดไฟล์ 6 รายการข้างต้นไปทับไฟล์เดิมตามตำแหน่ง (ไฟล์ teacher/ และ student/ ต้องอยู่ในโฟลเดอร์เดิม)
3) Commit และรอ GitHub Pages deploy
4) ปิดแอปเดิมทั้งหมด แล้วเปิดเว็บแต่ละลิงก์ใหม่ หากยังเห็นหน้าตาเดิมให้ล้างข้อมูลเว็บไซต์/ถอนติดตั้งแอปแล้วติดตั้งใหม่

ไม่ต้องรัน SQL Migration และไม่เปลี่ยนฐานข้อมูลหรือไฟล์ Edge Function
