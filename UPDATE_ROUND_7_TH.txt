STAR UP! ROUND 7 — STUDENT MISSION EXPERIENCE

สิ่งที่ปรับในรอบนี้
1) นักเรียนเห็นภารกิจทั่วไปและภารกิจด่วนในหน้าภารกิจด้วยการ์ดที่ชัดเจนขึ้น
2) แสดงเวลานับถอยหลังจากกำหนดส่งจริง โดยภารกิจด่วนใช้ urgent_until และภารกิจทั่วไปใช้ due_at
3) ภารกิจที่ยังไม่ถึงเวลาเริ่มจะยังไม่แสดง และระบบแจ้งเตือนจะเข้าคิวเมื่อถึง start_at
4) เมื่อครูเปลี่ยนชื่อ/วันเริ่ม/วันกำหนดส่ง/วันสิ้นสุด/ประเภท/สถานะ คิวเดิมจะถูกแทนที่ และคิวใหม่ทำงานตามตารางล่าสุด
5) ภารกิจที่อนุมัติสำเร็จ หมดเวลา หรือครูปิด จะย้ายจากรายการที่ทำได้ไปอยู่ประวัติภารกิจ
6) ประวัตินักเรียนแสดง 5 รายการแรกและมีปุ่มดูเพิ่มเติมทีละ 5 รายการ
7) ประวัติครูแสดงรายการเป็นชุดและมีปุ่มดูเพิ่มเติม
8) คิวแจ้งเตือนนักเรียนเรียงภารกิจด่วนก่อน และตรวจสอบทุก 5 วินาที
9) หน้าเว็บนักเรียนซิงก์ข้อมูลภารกิจ/กำหนดเวลา/ยอดดาวกับ Supabase ทุก 5 วินาที เพื่อเห็นการแก้ไขจากครูโดยไม่ต้องปิดแอป
10) ปรับ Service Worker cache version เพื่อให้ PWA รับไฟล์ใหม่

การติดตั้งฐานข้อมูล
1) สำรองฐานข้อมูล Supabase ก่อนทุกครั้ง
2) เปิด Supabase Dashboard > SQL Editor
3) เปิดไฟล์ migration_round7_student_missions_notifications_history.sql
4) ตรวจสอบ SQL แล้วรันหนึ่งครั้งในโปรเจกต์ Supabase เดิม
5) ตรวจสอบว่าฟังก์ชัน get_student_notifications, ack_student_notification,
   get_student_notification_history และ get_student_portal ถูกสร้าง/อัปเดตสำเร็จ
6) อัปโหลดไฟล์เว็บทั้งหมดเข้า GitHub Repository เดิม โดยรักษาโครงสร้างโฟลเดอร์

ข้อควรทราบ
- ไฟล์ SQL เป็น migration แบบเพิ่มส่วน ไม่ลบตารางหรือข้อมูลนักเรียน/ภารกิจ/หลักฐาน/ดาว/รางวัล
- มีการ baseline ภารกิจเดิมเป็นรับทราบแล้ว เพื่อไม่ให้เด็กได้รับแจ้งเตือนเก่าจำนวนมากทันทีหลังติดตั้ง
- ภารกิจใหม่และการเปลี่ยนกำหนดการจะเข้าคิวตาม start_at ล่าสุด
- ต้องทดสอบใน Supabase จริงหลังรัน migration เพราะไม่สามารถเชื่อมต่อฐานข้อมูลของผู้ใช้จากการแก้ไฟล์นี้ได้
- วิธีส่งภาพและข้อความ, student_submit_mission, teacher_review_mission และระบบเพิ่มดาวไม่ได้ถูกแก้ในหน้าเว็บรอบนี้
